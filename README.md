# Assignment 4: Higher-Order Functions and Decorators

This branch contains the fourth Python assignment.

- `newton.py`: annotated reference implementation of Newton's method for square roots.
- `hop_decorator.py`: completed exercises on inner functions, loop-based Newton iteration, logging, timing, and memoization decorators.

Run the assignment examples with Python 3:

```sh
python3 hop_decorator.py
```

The timing examples include pauses of 1 and 6 seconds, so a full run takes approximately seven seconds. Both source files contain detailed English comments.
